# 06 · AIGC 使用说明

> 赛事要求交「创作说明（AIGC 工具与思路）」。本文就是那份说明的完整版，可直接粘进报名表；
> 简版在 `submission/创作说明.md`（600 字以内）。

## 一句话

**AI 只做一处：把 18 张图版画出来。其余全是代码——运镜、转场、颗粒、字幕、声音、混音，逐帧算出来的。**

## 用了什么

| 环节 | 工具 / 方法 | 生成还是程序 | 说明 |
| --- | --- | --- | --- |
| 画面素材 | 文生图模型（ImageGen），18 张 | **生成** | 每张的提示词都是显式写死的（`story.py` 的 `PLATES`），没有"抽卡"式反复试；风格前缀统一为「大漆工艺微距摄影，深黑漆底，24K 金线浮雕」 |
| 镜头运动 | Python + Pillow | 程序 | 不用视频生成模型。每镜是一个**取样窗**在 1536×1024 图版上按 `z`（放大率）与 `c`（中心点）做缓动裁切，再放大到 1920×1080 |
| 转场 | Python + numpy | 程序 | 全片 16 处转场由同一条"金线"完成：先把一条曲线预计算成**弧长图**与**距离图**（480×270 网格，双线性放大），再按距离/弧长阈值决定每个像素取前一镜还是后一镜 |
| 颗粒 / 暗角 / 提亮 | numpy | 程序 | 6 张 2× 降采样高斯噪声循环使用；径向暗角；逐帧确定性（同 seed 同帧） |
| 字幕 | Pillow + Noto Serif SC | 程序 | 46px、2px 黑描边、柔投影；文字内容写在 `story.py` |
| 旁白 | edge-tts（微软语音合成，`zh-CN-YunxiNeural`，rate −12%） | **合成语音** | 19 句，逐句生成后按镜头起点对齐 |
| 音效 | numpy 合成 | 程序 | 舂泥（低频闷响+粉料碎裂）、搓线（带周期调制的摩擦）、贴金（3 个高频分音+气声）、磬（非谐分音长衰减）、毛笔、呼吸、室内底噪 |
| 配乐 | numpy 合成 | 程序 | 箫（谐波+气声+4.4Hz 颤音，五个乐句）+ 低音垫（73/110/147Hz 三个五度，慢呼吸） |
| 混音 | numpy + ffmpeg | 程序 | 旁白处按包络压掉 35% 配乐（ducking）；软限幅只削瞬态；ebur128 迭代对齐响度 |
| 编码 | ffmpeg / libx264 | 程序 | CRF 21，yuv420p，High@4.1，AAC 192k |

## 没用

- 没有视频生成模型（没有 Runway / 可灵 / Sora）。片子里的"动"全部来自**静帧 + 程序化运镜**。
- 没有真人素材、没有实拍、没有第三方素材库、没有版权音乐。
- 没有换脸、没有声音克隆（旁白是标准合成音色，不对应任何真人）。
- 没有"AI 一键成片"工具；每一帧都可复现（`py -3 scripts/build.py`）。

## 人做了什么

| 人做的 | 具体 |
| --- | --- |
| 选题与史实 | 十条可引用事实逐条核对（`docs/01-STORY.md`），刻意不写无出处的年份与人名 |
| 视觉纲领 | 决定"只讲线"、只留三色、不要人脸；决定开场用空的黑漆面 |
| 分镜与文案 | 20 镜时长、19 句旁白、每镜的转场曲线 |
| 判据 | 写了 47 条断言（时长/画幅/字幕上屏/水印避让/响度/静音/缺字），片子不达标就不许交 |
| 取舍 | 开场从 13s 砍到 10s（原来前 2 秒几乎全黑）；结尾从 12s 砍到 10s；两处同图版硬切改成线转场 |

## 可复现

```bash
pip install -r requirements.txt
py -3 scripts/build.py      # 声音 + 4308 帧 + 拼接 + 混音 + 压制，约 40 分钟（4 进程）
py -3 scripts/verify.py     # 47 条断言
```

图版是生成物，随仓库一起提交（`assets/plates/P00–P17.png`），所以**不重新生图也能 1:1 复现成片**。
`build/video` 全流程除了 TTS 之外没有随机性（TTS 结果已缓存为 `build/vo/*.mp3`）。

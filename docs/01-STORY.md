## 刻意没说的

| 想说的 | 为什么不说 |
| --- | --- |
| 「蔡氏第 13 代传人是蔡水况」 | **错**。他是第 12 代；13 代是蔡彩羡（ihchina 项目页）。片子只说「蔡氏 13 代」这个整体事实，不把代数安到人头上。 |
| 「漆线雕起源于唐代/宋代」 | 名录只说到「受宋元线雕工艺特别是沥粉和泥线雕的启发」「形成于明末清初」。再往前是猜。 |
| 「三百多年前具体哪一年」 | 没有可引用的确切年份。片子里只出现「三百多年」。 |
| 「蔡水况为它命名时写下了这三个字」 | 央视说「灵机一动取名」，中新网说「辗转反侧好几个晚上，终于想出」。片子里取后者（「想了几夜」），末句用「写下三个字」是取「『漆线雕』三个字见报后，沿用至今」（中新网）之意，**不是引语**，说明文里也这样标。 |
| 具体作品名（《还我河山》《波月洞悟空降妖》） | 与「线」这条主线无关，塞进去会变成履历片。 |

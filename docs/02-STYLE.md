# 02 · 视觉系统

## 一句话

**黑漆底，一根金线。** 全片只有三种颜色：漆黑、金、极暗的朱红。
不靠"堆画面"制造信息量，靠「线在画面里的位置」制造信息量。

## 色与光

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 金（标准差） | `#D6AA5C` / 高光 `#FFE8B2` | 金箔在侧光下的实测色，不是"金色"这个概念的色 |
| 底 | 近黑（实测 p99 ≤ 60） | 大漆的黑是有反光的黑，不是纯黑，所以留 2–5% 的底部微光 |
| 第三色 | 极暗朱红 | 只出现在漆泥与砖粉上，不用于强调 |
| 光位 | 左上斜射，高光压在金线脊上 | 让「线是立起来的」这件事在每一帧都成立 |
| 暗角 | 径向，中心 1.0 → 边缘 0.42 | 把注意力压到画面中间 78% |

## 工具水印与安全区

生图通道会在图版右下角打「AI生成 / WORKBUDDY」水印。实测位置（1536×1024 原图，阈值 L>110）：

```
x ∈ [0.921, 0.993]     y ∈ [0.940, 0.989]
```

所以：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `SAFE_BOTTOM` | 0.905 | 取样窗下边界上限，比水印上沿还留 3.5%（36 px） |
| `SAFE_RIGHT` | 0.995 | 右边界（宽度由画幅比决定，通常用不满） |

`render.window()` 里这条是硬约束：宁可缩小放大率，也不让取样窗进水印。
`verify.py` 的 AC-11 会在成片右下角再量一次高亮像素占比。

## 运镜

不用推拉镜头语言，只用**取样窗**：

```
z: 1.00 → 1.06      几乎不动的推
c: (0.50,0.50) → (0.52,0.50)   横向 2% 的漂移
```

全片最大放大率 1.46，最小 1.00。**没有一镜是"平移划像"**——因为 18 张图版的横向余量只有 9%（安全区限制），横移会立刻拍到水印。

## 转场：线

不用淡入淡出、不用划像。所有转场由同一条金线完成：

| 模式 | 做法 | 用在哪 |
| --- | --- | --- |
| `bloom` | 线先落在画面里，图形沿"到这条线的距离"从线向两边绽开 | 起（P00→P01） |
| `wipe` | 线在画面里走，**走过的顺序就是画面显影的顺序** | 其余 15 处 |

曲线 6 种：`sweep`（微下垂横线，与 P01 里那根线对齐）/ `wave` / `coil`（盘线）/ `diag` / `stair`（甲片）/ `dragon`（龙身三转折）。

`verify.py` 的 AC-10b 会在 6 处转场中点抽帧，量金线像素是否真在场——**转场不能只是"概念上存在"**。

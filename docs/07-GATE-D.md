# 07 · 闸 D（第一眼）

> 规则（本工作区的《打比赛》流程）：成品与 ≥5 件"尺子"混排盲排，至少两位未参与本单的评委各自排名，
> 排在至少 3 件尺子之上才算过线。

## 这场赛事的特殊性：没有尺子

「云创福建」AIGC 创作大赛是**首届**，2027 年 1 月才第一次评审——**不存在往届得奖作**，
无法按"与往届得奖作混排"的原判据执行。

同时，本机下载不到外部影像素材（视频站与图站要么 403 要么验证码），
没法临时扒一堆同类非遗 AIGC 短片当尺子。这一点如实记录，不假装有尺子。

## 替代判据（沿用本工作区"首届赛事"的做法）

**六帧盲读**：把成片里的六帧按顺序交给**两位未参与本单的评委**（不同模型家族），
不给片名、不给字幕、不给上下文，只问三件事：

1. 这门手艺是什么、在做什么？
2. 这六帧连起来讲了什么事？
3. 哪一格最像"废帧"？哪一格第一眼根本看不出是什么？

判过线的标准（先写死，再看结果）：

- **A 可读**：两位评委都能说出"这是一门在器物/神像上做立体线条装饰的手艺"这一类判断（不必说出"漆线雕"三个字）。
- **B 有事**：两位评委复述的"讲了什么事"方向一致（做东西 → 上器 → 成品），不是六张互不相干的静物。
- **C 无废帧**：被两位同时点名"删掉也不影响"的帧 ≤1 格；若被同时点名，就改。

三条全中才算过线；有任意一条不中，按两轮就停的规矩：改一轮再测，仍不中就把结果交回用户裁决。

## 与"尺子"相比缺什么

首届赛事没有尺子，意味着**闸 D 在这里只能给出"可读 / 有事 / 无废帧"的下限判断，给不出"能排到第几"**。
这一条限制必须写在给用户的结论里，不能含糊过去。
